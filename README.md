# DataAnalysisRR_SalesPerformanceDashboard
The dashboard present to the stakeholders in one view, Sales Performance of a Subsidiary of the business. 

1. Connected to Microsoft 365 BC using the connector in Power Query.
2. Extracted the required data using OData Rest API from BC.
3. Cleaned and transformed the dataset in Power Query.
4. Created the semanic model, public and share in Power BI service.
5. Built report and virtualize data in a Power BI report from the shared semantic model
